编写文档与层级关系

每篇文档通过 frontmatter 控制元数据与层级：

字段 说明
title 文档标题（侧边栏显示）
parent 父文档的 slug，留空为顶级
order 同级排序，数字越小越靠前
group 设为 true 显示为可折叠分组
tags 标签，逗号分隔
description 一句话简介

---
title: 子文档
parent: guide      # 父文档 slug
order: 1
---
