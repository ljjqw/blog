欢迎来到我的博客 🎉

这是一个用免费方案搭建的个人博客，整个工作流只需要 Node.js：

  • 写作：在 src/posts 下新建 .md 文件（支持 frontmatter 元信息）
  • 构建：npm run build 把 Markdown 编译为静态 HTML
  • 预览：npm run serve 启动本地服务
  • 部署：npm run deploy 一键发布到 GitHub Pages（完全免费）

如何写一篇新文章

在 src/posts 目录新建一个 .md 文件，顶部写上元信息：

---
title: 文章标题
date: 2026-09-02
tags: 技术, 随笔
description: 一句话简介
---

你的正文内容……

保存后运行 npm run build 即可在首页看到它。

支持的 Markdown 语法

  • 标题、加粗、斜体、行内代码
  • 有序 / 无序列表
  • 引用块
  • 代码块
  • 链接

提示：所有样式都在 src/assets/style.css 中，可自由修改主题。

祝写作愉快！
